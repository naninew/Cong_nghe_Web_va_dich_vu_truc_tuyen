What is the worst-case auxiliary space complexity of recursive Depth-First Search (DFS) on a binary tree with maximum depth h?

A O(1)
Your Answer close
B O(h)
Correct Answer check
C O(2^h)
D O(log h)
lightbulb Comprehensive Solution & Memory Anchor

In recursive DFS, each recursive descent pushes a new execution stack frame. In the worst case of a skewed tree or traversing down to the deepest leaf, the call stack holds exactly h stack frames simultaneously. Therefore, auxiliary space is directly proportional to tree height O(h), not constant O(1).
